## About Me

Full-stack developer who builds clean, dependable applications end to end — from database schema and REST APIs to responsive, accessible front ends. I work comfortably across the **Java/Spring Boot** and **Python/FastAPI** backend stacks, with **React + TypeScript** on the front end, and I care about code that is readable, tested, and ready for production.

- 🔭 Building real-time, API-driven, and full-stack web applications
- 🧩 Comfortable across backend, frontend, and database layers
- 🛠️ Strong on REST API design, real-time WebSocket systems, and clean architecture
- 🌱 Always sharpening fundamentals through hands-on, shipped projects
